## 게임 소개

고전적인 블록깨기 게임을 모티브로 몬스터, 성장, 공격 요소를 더한 RPG 게임입니다.  
아래로 흘러내려오는 맵에서 패들로 공을 튕겨 몬스터를 공격하고, 레벨이 오르면 강화 카드를 골라 공과 패들을 성장시키며 보스에 도전합니다.

## 담당 작업

### 공의 이동과 반사
- `Rigidbody2D`를 쓰지 않고 속도를 직접 적분하는 방식으로 공의 이동과 반사를 구현했습니다.
- 벽과 지형의 반사 계산과 패들의 반사 계산을 나누고, 패들은 맞은 위치에 따라 반사각이 달라지게 했습니다.

### 고속 터널링 해결
- 공이 빨라지면 한 프레임에 벽을 지나쳐 버리는 문제가 있어, 이동 경로를 원으로 훑어(`CircleCast`) 가장 먼저 닿는 충돌을 찾는 방식으로 바꿨습니다.

### 스킬 시스템
- 스킬을 추상 클래스로 두고 지속 시간, 수동 발동과 자동 발동, 각각의 쿨다운을 공통으로 처리하게 했습니다.
- 그 위에 거대화와 분신 스킬을 구현했습니다.
- 입력과 스킬을 ScriptableObject 이벤트 채널로 연결해 서로 직접 참조하지 않게 했습니다.

### 그 밖의 구현
- 적 상태 머신(대기, 이동, 추적, 공격)
- 버프 뱃지, 스킬 쿨다운 표시, 체력과 경험치 HUD
